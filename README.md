# 阿公台語語音：試聽

先聽「阿公本人」當對照，再聽各版本。聽的時候注意：口音像不像台灣台語、聲調有沒有唸錯、抑揚頓挫和重音像不像阿公、語速。相似度是跟阿公去噪錄音比（阿公自己前半對後半是 0.90）。

## 路線 A 第二輪：資料增強＋音調轉移（已刪「大家好」、放慢）

用約 9 分鐘的增強資料重新訓練，語速放慢到每秒約 2.6 字。阿公的音高：中位數 142 Hz、起伏 10.7 半音、句尾下降 1.3 半音。建議先比 A、B（最像阿公的音色）和 D（音高起伏最像阿公）。
